# FLO MODE Fashion Store

## Project Overview
FLO MODE is a fashion store website that displays clothing and footwear products with images, descriptions, and prices. The project was developed in two versions to compare traditional CSS with Tailwind CSS.

## Technologies Used
- HTML5
- CSS3
- Tailwind CSS
- Git and GitHub

## Project Versions

### Version 1: HTML and CSS
In the first version, I used HTML to structure the website and a separate `style.css` file to design it. I wrote CSS rules manually to control colors, spacing, layouts, fonts, and responsive design.

### Version 2: HTML and Tailwind CSS
In the second version, I used Tailwind CSS utility classes directly in the HTML file. Instead of writing many custom CSS rules, I applied classes such as `flex`, `grid`, `bg-orange-50`, `p-6`, and `md:flex-row` to style the website.

## Differences Between CSS and Tailwind CSS

| Traditional CSS | Tailwind CSS |
|---|---|
| Styles are written in a separate CSS file. | Styles are applied using utility classes in HTML. |
| Custom class names are created. | Ready-made utility classes are used. |
| More manual CSS writing is required. | Styling can be done directly in HTML. |
| HTML is cleaner, but styling is managed separately. | HTML can become longer because of many utility classes. |

## What Changed in My Workflow?
When using traditional CSS, I first created the HTML structure and then wrote CSS rules in a separate file. I had to create and manage classes for the different website sections.

When I switched to Tailwind CSS, I applied utility classes directly to HTML elements. This made styling and changing layouts faster and helped me implement responsive design using classes such as `md:flex-row` and `md:grid-cols-3`.

I learned that traditional CSS gives me more freedom to organize custom styles, while Tailwind CSS helps me build and adjust interfaces quickly using predefined utility classes.

## How to Run
1. Clone or download this repository.
2. Open the project in Visual Studio Code.
3. Open the version you want to test.
4. Open its `index.html` file in a browser.

For the Tailwind CDN version, an internet connection is required.

## Conclusion
This project helped me understand the difference between traditional CSS and Tailwind CSS and how both approaches can be used to create responsive websites.
